## 🔊 Scenery sounds
- A new **Scenery sounds** menu in the Lore Studio Bridge's Module Settings. List your sounds once (Rain, Forest, Wind...), choosing each one's file and volume, with a button to preview it.
- **Weather sounds:** choose which sound plays for rain, thunderstorms, snow, blizzards, hail, sandstorms, wind and fog. If you haven't chosen one, a close match fills in: a thunderstorm uses your rain sound, a sandstorm uses wind.
- **Scene ambience:** choose a sound to loop on each scene, like Forest on your forest scenery. It plays under any weather sound.
- Sounds fade in and out on every player's screen as the scene, the weather and the time of day change. A file named like `forest_day.ogg` / `forest_night.ogg` follows the time of day, the same way backgrounds do.
- They follow each player's own **Ambient** volume.

## 🌦️ Gentler weather
- Weather effects on scenery are much calmer by default: slower, lighter and more see-through, with clouds and fog slowed down the most.
- A new **Weather strength** setting (10–100%) sets how strong they are. 100% uses FXMaster's own settings, like 0.10.0 did.
- Sandstorms no longer show up as thunderstorms. "Sandstorm" contains "storm", so 0.10.0 played rain and clouds for it.
