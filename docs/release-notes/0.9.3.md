## 🔌 A quieter Foundry bridge
- While Lore Studio is closed, the Foundry module stops sending and checks back once every 30 seconds, so the Foundry console no longer fills with connection errors.
- Chat, rolls and combat keep queueing while Lore Studio is closed, so nothing from the session is lost.
- When you open Lore Studio, the bridge reconnects by itself. You don't need to reload Foundry anymore.
