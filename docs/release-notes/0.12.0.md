## 🎨 CSS themes
- Drag a `.css` theme file onto **Settings → Appearance** and it's installed and switched on straight away. You can drop it anywhere on the page, or click the new drop zone to choose a file.
- Keep as many as you like: switch between them, turn them off or delete them in the new **CSS themes** card.
- They're saved in Lore Studio's own data folder, so updates never touch them, and they're included in backups.
- Your `custom.css` still loads last, so it wins over a CSS theme.
