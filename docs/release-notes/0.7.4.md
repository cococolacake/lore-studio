- **Before-session checklist** (Settings → Campaign, off until you switch it on): reminders you tick off before each session. Reminders for every session, plus one-offs for a single session. It shows on the next session's Plan tab and on Home, and Live mode reminds you of anything unticked.
- **Live mode: you decide when a scene is finished.** Opening a scene no longer marks it played. Tick it in the scene list or press **Mark finished**, and untick it any time. Recap drafts use the scenes you marked.
- **Live mode: beats tick from their own box,** so clicking a beat's text to read it no longer ticks it off.
