- **Fix: editing a scale value could leave empty levels behind.** When a saved scale value had fewer levels than before (or changed from Die to Number), Foundry kept the old levels with no value, so the character could end up with "null" at their level. Lore Studio now writes every level from the first value up to 20, carrying each value forward, so nothing stale survives. The page still shows only the levels where the value changes.
- **Update the Foundry module** to 0.8.8 (Add-on Modules → Update, then reload Foundry). Lore Studio asks for it before editing scale values.
