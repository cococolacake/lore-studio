## 🌦️ Gentler weather
- Weather effects on scenery are much calmer by default: slower, lighter and more see-through, with clouds and fog slowed down the most.
- A new **Weather strength** setting in Module Settings (10–100%) sets how strong they are. 100% uses FXMaster's own settings, like 0.10.0 did.
- Changing the setting updates the weather on the current scene straight away.
