- **Notice files changed outside Lore Studio.** If another app edits your campaign's Markdown files while Lore Studio is open (the Claude app with the folder connected, Obsidian, a text editor), a notification says which page or session changed, with **Refresh**. If it's not the page you're on, there's also **Open**. Several changes at once come as one notification with a list. Lore Studio's own saves don't trigger it. Turn it off in Settings → Reading.
- **Refresh button** in the sidebar (above the light/dark switch): redraws the current page from the files on disk. A dot on it means something changed outside Lore Studio.
- Refreshing asks first if you have unsaved edits on the page, and a session plan you were editing isn't auto-saved over the outside change.
