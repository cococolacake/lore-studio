**Important fix for the hit point fixer. Update the Foundry module too** (Add-on Modules → Update, or Settings → Foundry → Install), then reload Foundry. Lore Studio won't run the fixer with an older module.

- **Fix:** on a character whose class has no per-level hit points (common with homebrew classes) and whose max HP was set by hand, the fixer could stop the hand-set max and leave them at 0 max HP. It now never writes a change that ends at 0 max HP: it puts everything back and says so.
- **Fix level by level** now works for homebrew classes: Lore Studio adds the hit point records to the class, so future level-ups add HP as normal. Once every level has a value, you can stop setting max HP by hand.
- **Set max HP exactly** is there as a quick option too.
- Nothing destructive is ticked by default, a max set by hand or a bonus is shown as "good to know" rather than as a problem, and current HP stays sensible.
- **Undo last fix**: Lore Studio saves what was on the sheet before every fix and can put it back exactly.
