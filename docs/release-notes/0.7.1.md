A small update to the public beta.

- **Copy diagnostics** in Settings → About: a short report of your setup to paste into bug reports. API keys, tokens, webhooks and campaign text are never included.
- **Report a bug** button next to it.
- **Settings → AI → Show AI features**: switch AI off to hide chat, recap drafting, scene ideas, tag suggestions and thread checks.
- Player lore book: sub-page cards, quotes and callouts now look like they do in the app, the site uses your accent colour, and header images that can't load fold away.
- The README now says what Lore Studio sends where, and there are new SECURITY.md and CONTRIBUTING.md files.
