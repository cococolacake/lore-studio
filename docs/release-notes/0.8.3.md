- **Export everything** (Settings → Campaign): one .zip with the whole campaign (lore, sessions with plans, transcripts, recaps, live notes and Foundry logs, maps, monsters, encounters, boards, handouts, calendar, timeline, clocks, threads, chats and the party) plus Lore Studio's settings and themes. API keys, passwords and Discord webhooks are left out unless you choose to include them; session recordings are optional. It comes with a README explaining what's inside.
- **Restore a backup** (welcome screen, or Settings → Campaign): unpacks it into a new folder and opens it. Nothing is overwritten, recordings are re-linked, and keys you've already entered on this computer are kept.
