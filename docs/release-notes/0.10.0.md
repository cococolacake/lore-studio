## 🌅 Scenery that keeps time
- **Scenery fits the screen.** Scenes in your scenery folder (**Static Scenery** by default, set in Module Settings) are sized to 1920×1080, and their backgrounds fill the screen with the edges cropped. Your image files aren't changed.
- **Backgrounds follow the time of day.** Name a scene's images like `canyon_dawn.webp`, `canyon_day.webp`, `canyon_dusk.webp` and `canyon_night.webp`, in the same folder, and set the scene to any one of them. The background changes with Calendaria's clock and its sunrise and sunset. If a version is missing it's skipped, so a scene with only day and night works too.
- **Changes crossfade.** When the time of day changes, every player's screen fades from the old background to the new one. You can set how long the fade takes, or turn it off, in Module Settings.
- This works without Lore Studio open. If you used the separate Day/Night Backgrounds module, turn it off so the two don't both switch backgrounds.

## 🔌 A quieter Foundry bridge
- While Lore Studio is closed, the Foundry module stops sending and checks back once every 30 seconds, so the Foundry console no longer fills with connection errors.
- Chat, rolls and combat keep queueing while Lore Studio is closed, so nothing from the session is lost.
- When you open Lore Studio, the bridge reconnects by itself. You don't need to reload Foundry anymore.
