## 🌅 Scenery that keeps time
The Foundry module now runs your scenery, with or without Lore Studio open. Put scenery scenes in a scene folder called **Static Scenery** (or set your own name in Module Settings). Each part below can be switched off there.

- **Scenery fits the screen.** Scenery scenes are sized to 1920×1080 with no grid, and their backgrounds fill the screen with the edges cropped. Your image files aren't changed.
- **Backgrounds follow the time of day.** Name a scene's images like `canyon_dawn.webp`, `canyon_day.webp`, `canyon_dusk.webp` and `canyon_night.webp`, in the same folder, and set the scene to any one of them. They follow Calendaria's clock and its sunrise and sunset. A missing version is skipped, so a scene with only day and night works too.
- **Changes crossfade.** When the time of day changes, every player's screen fades from the old background to the new one. You can set how long the fade takes, or turn it off.
- **Sounds follow the time of day.** Ambient sounds on the scene and playing playlist sounds switch between files named the same way, like `forest_day.ogg` and `forest_night.ogg`.
- **Weather.** With FXMaster, Calendaria's weather plays on scenery scenes: rain, storms, snow, hail, fog, clouds and embers, plus sandstorms with FXMaster+. You can turn it on for every scene too.
- **Scenery mode.** On scenery scenes, players see just the picture: no scene controls or token HUD, and the view stays fitted to their screen.
- If you used the separate Day/Night Backgrounds module, turn it off so the two don't both switch backgrounds.

## 🗺️ Show the players a place
- A new **map button** on lore pages shows the players that place in Foundry, crossfading into it. Lore Studio uses the scene named like the page, or asks which one and remembers it. The linked scene shows under the page title, where you can unlink it.
- In live mode, scenery scenes crossfade too when you activate them.

## 📜 Recaps know where you were
- The Foundry log now notes the time of day, the in-game date and the weather with each scene, and again when they change. Recaps can say the fight happened at dusk in a sandstorm.

## 🔌 A quieter Foundry bridge
- While Lore Studio is closed, the Foundry module stops sending and checks back once every 30 seconds, so the Foundry console no longer fills with connection errors.
- Chat, rolls and combat keep queueing while Lore Studio is closed, so nothing from the session is lost.
- When you open Lore Studio, the bridge reconnects by itself. You don't need to reload Foundry anymore.
