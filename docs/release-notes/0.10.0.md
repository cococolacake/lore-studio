## 🌅 Scenery backgrounds in Foundry
The Foundry module can now look after your scenery scenes. This works even when Lore Studio is closed. Find the settings under **Module Settings → Lore Studio Bridge**.
- **Fit to 1920×1080.** Scenes in your scenery folder (**Static Scenery** by default) are sized to 1920×1080, and their backgrounds fill the screen with the edges cropped. Your image files aren't changed.
- **Time of day.** Name a scene's images like `canyon_dawn.webp`, `canyon_day.webp`, `canyon_dusk.webp` and `canyon_night.webp`, and the background follows the clock. It uses Calendaria's sunrise and sunset if you have it. Missing versions are skipped, so a day/night pair is enough.
- **Crossfades.** When the background changes, every player's screen fades smoothly from the old image to the new one. You can set how long the fade takes, or turn it off.

## 🔌 A quieter Foundry bridge
- While Lore Studio is closed, the Foundry module stops sending and checks back once every 30 seconds, so the Foundry console no longer fills with connection errors.
- Chat, rolls and combat keep queueing while Lore Studio is closed, so nothing from the session is lost.
- When you open Lore Studio, the bridge reconnects by itself. You don't need to reload Foundry anymore.
