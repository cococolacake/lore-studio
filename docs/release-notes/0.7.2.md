- **One file per person:** on a session's Transcript tab, **Attach one file per person** takes a Craig download (the .zip or the unzipped folder). Each person's file is transcribed on its own and labelled with their name. Names are matched to your party list and remembered for next time; mark your own file as GM and skip bots.
- **Better voice separation:** when telling voices apart, lines are now split at the word where someone else starts talking, instead of the whole line going to one person.
- **Settings → OBS:** clearer steps for putting Discord on its own track.
- **Boards:** strings now pin to the exact spot you click on each item, and you can drag a pin to move it. String colours now change reliably. Pictures no longer need a caption: add or remove one from the picture's toolbar.
